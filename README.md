# Magnetic-Navigation

This project was done in a group setting over the course of four months utilizing a new idea communicated by a professor.
The main inspiration for this project is to develop a new version of the GPS using the magnetic field of the earth outputting XYZ coordinates of your exact location.
An Arduino board was the main portion to connect all wires and important components, which the most important is the magnometer to read the magnetic field dependant on where its pointing.
